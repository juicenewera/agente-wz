# Contribuindo

1. Crie um fork e uma branch curta.
2. Não inclua números reais, conversas, tokens, sessões ou dados de CRM nos testes.
3. Execute `npm test` antes de abrir o pull request.
4. Mantenha contratos de provedores dentro de `src/providers/`.
5. Mudanças no contrato interno de mensagem devem atualizar os dois adapters e os testes.

Ao contribuir, você concorda em licenciar sua contribuição sob a licença MIT deste starter.
